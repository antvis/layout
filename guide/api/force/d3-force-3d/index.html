#D3Force3D (3D force)Iterative

D3Force3DLayout is based on d3-force-3d, adding z-axis forces on top of 2D. It is suitable for 3D scenes or depth-layered views.

#When to use

  • 3D rendering or layouts that need z coordinates
  • Reduce occlusion through depth layering

#Input requirements

  • Nodes must have unique id
  • edges are recommended because link forces depend on relationships

#Usage

import { D3Force3DLayout } from '@antv/layout';

const layout = new D3Force3DLayout({
  width: 800,
  height: 600,
  iterations: 300,
});
await layout.execute(data);
layout.forEachNode((node) => console.log(node.id, node.x, node.y, node.z));

#Options

This page lists all options for D3ForceLayout. It supports two configuration styles:

  1. Shorthand fields: quick access to common settings like centerX, linkDistance, nodeStrength.
  2. Force objects: closer to the original d3-force API, such as link, manyBody, collide, x, y, center, radial.

You can mix both; when both are provided, the force objects are usually more predictable.

#Force objects

These force objects can be set to false to disable; otherwise configure fields as in d3-force.

#collide

  • radius?: number | (node, index, nodes) => number
  • strength?: number
  • iterations?: number

#manyBody

  • strength?: number | (node, index, nodes) => number
  • theta?: number
  • distanceMin?: number
  • distanceMax?: number

#link

  • id?: (edge, index, edges) => string
  • distance?: number | (edge, index, edges) => number
  • strength?: number | (edge, index, edges) => number
  • iterations?: number

#x /y

  • strength?: number | (node, index, nodes) => number
  • x?: number | (node, index, nodes) => number (only for x force)
  • y?: number | (node, index, nodes) => number (only for y force)
