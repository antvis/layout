# MDS Layout <Badge text="Non-Iterative" type="tip" />

MDS stands for Multidimensional Scaling. It maps ideal distance relationships onto a 2D plane, useful when you want a balanced global structure and edge lengths close to expected values.

<img width="400" src="https://mdn.alipayobjects.com/huamei_qa8qxu/afts/img/A*myM6T6R_d34AAAAAAAAAAAAADmJ7AQ/original" />

## When to use

- You want a more balanced overall structure
- Ideal edge lengths are the primary constraint

## Input requirements

- Nodes must have unique `id`
- `edges` are recommended for distance constraints. If the graph is sparse or disconnected, results may be more sensitive to initial conditions.

## Usage

```ts

const layout = new MDSLayout({ width: 800, height: 600, linkDistance: 200 });
await layout.execute(data);
```

## Options

<CommonLayoutOptions />


### Algorithm options

| Option          | Description            | Type     | Default |
| --------------- | ---------------------- | -------- | ------- |
| `linkDistance`  | Ideal edge length      | `number` | `200`   |

:::note
MDS works best when distance constraints are explicit. If you need continuous convergence or more local constraints, consider an iterative force-directed layout.
:::
