# D3Force3D 3D 力导向 <Badge text="Iterative" type="info" />

`D3Force3DLayout` 基于 `d3-force-3d`，在二维力导向的基础上增加 z 轴计算，适用于 3D 场景或需要深度分层的表达。

![d3-force](https://mdn.alipayobjects.com/huamei_qa8qxu/afts/img/A*4mbSTJLOXkgAAAAAAAAAAAAADmJ7AQ/original)

## 适用场景

- 3D 渲染或需要 z 轴信息的布局
- 希望通过深度分层降低遮挡

## 输入要求

- 节点需要可唯一标识的 `id`
- 推荐提供 `edges`，因为 link 力依赖边关系

## 用法

```ts

const layout = new D3Force3DLayout({
  width: 800,
  height: 600,
  iterations: 300,
});
await layout.execute(data);
layout.forEachNode((node) => console.log(node.id, node.x, node.y, node.z));
```
