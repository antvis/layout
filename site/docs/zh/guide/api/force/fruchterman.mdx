# Fruchterman 力导布局 <Badge text="Iterative" type="info" />

Fruchterman-Reingold 是经典力导向布局之一，使用斥力/引力/重力使图结构在平面上达到相对均衡的分布。

<img
  width="400"
  src="https://mdn.alipayobjects.com/huamei_qa8qxu/afts/img/A*1AvnTorIogUAAAAAAAAAAAAADmJ7AQ/original"
/>

## 适用场景

- 中小规模图的通用力导向布局
- 需要较均衡的全局结构

## 输入要求

- 节点需要可唯一标识的 `id`
- 推荐提供 `edges`，用于引力与结构约束

## 用法

```ts

const layout = new FruchtermanLayout({
  width: 800,
  height: 600,
  maxIteration: 500,
});
await layout.execute(data);
```

### 迭代控制

```ts
layout.restart();
layout.tick(10);
layout.stop();
```

### 算法配置

| 配置项           | 说明                                     | 类型                       | 默认值      |
| ---------------- | ---------------------------------------- | -------------------------- | ----------- |
| `gravity`        | 向中心的吸引力，越大越紧凑               | `number`                   | `10`        |
| `speed`          | 每次迭代节点移动速度                     | `number`                   | `5`         |
| `clustering`     | 是否按聚类布局                           | `boolean`                  | `false`     |
| `clusterGravity` | 聚类内部重力。`clustering=true` 时生效。 | `number`                   | `10`        |
| `nodeClusterBy`  | 聚类字段名或函数                         | `string \| (node)=>string` | `'cluster'` |
