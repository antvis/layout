# AntVDagre 层次布局 <Badge text="Non-Iterative" type="tip" />

面向流程图与依赖图等场景的层次布局实现，提供方向、间距、对齐与边控制点等更直接的配置项。

<img
  width="400"
  src="https://mdn.alipayobjects.com/huamei_qa8qxu/afts/img/A*gQGOTYlN6BMAAAAAAAAAAAAADmJ7AQ/original"
/>

## 适用场景

- 流程图与依赖图等层次结构表达
- 需要输出折线控制点与边路径信息，以便直接渲染

## 输入要求

- 节点需要可唯一标识的 `id`
- 需要提供 `edges`，并确保 `source/target` 可对应到节点 id
- 若涉及 Combo 或嵌套结构，建议提供 `parentId`。你可以通过 `node` 映射函数适配该字段。

## 用法

```ts

const layout = new AntVDagreLayout({ rankdir: 'TB', nodesep: 50, ranksep: 50 });
await layout.execute(data);
```

### 算法配置

| 配置项           | 说明                                     | 类型                                                  | 默认值      |
| ---------------- | ---------------------------------------- | ----------------------------------------------------- | ----------- |
| `rankdir`        | 布局方向，可选 TB、BT、LR、RL            | `DagreRankdir`                                        | `'TB'`      |
| `ranker`         | 排序模式                                 | `'network-simplex' \| 'tight-tree' \| 'longest-path'` | `undefined` |
| `align`          | 节点对齐方式                             | `DagreAlign`                                          | `'UL'`      |
| `begin`          | 左上角起始位置                           | `Point`                                               | `undefined` |
| `nodesep`        | 同层节点间距                             | `number \| (node)=>number`                            | `50`        |
| `ranksep`        | 层间距                                   | `number \| (node)=>number`                            | `50`        |
| `nodesepFunc`    | 同层节点间距回调。优先级高于 `nodesep`。 | `(node)=>number`                                      | `undefined` |
| `ranksepFunc`    | 层间距回调。优先级高于 `ranksep`。       | `(node)=>number`                                      | `undefined` |
| `nodeSize`       | 节点大小，用于占位与间距计算。           | `Size \| (node)=>Size`                                | `undefined` |
| `controlPoints`  | 是否同时计算边控制点                     | `boolean`                                             | `false`     |
| `sortByCombo`    | 是否按 parentId 排序以减少 Combo 重叠    | `boolean`                                             | `false`     |
| `edgeLabelSpace` | 是否为边 label 预留空间                  | `boolean`                                             | `true`      |
| `nodeOrder`      | 同层节点顺序参考，按节点 id 指定         | `string[]`                                            | `undefined` |
| `radial`         | 是否基于 dagre 做辐射布局                | `boolean`                                             | `undefined` |
| `focusNode`      | 关注节点。`radial=true` 时生效。         | `ID \| Node \| null`                                  | `undefined` |
| `preset`         | 参考节点位置，用于连续布局               | `NodeData[]`                                          | `undefined` |

:::note controlPoints
`controlPoints: true` 会为边结果补充控制点信息，便于直接绘制折线边。具体消费方式取决于渲染组件或图引擎。
:::

## 输出字段

可通过 `forEachEdge` 读取边的额外输出字段：

- `edge.points?: Point[]`
- `edge.labelPos?` / `edge.labelOffset?` / `edge.labelSize?`：当开启 label 预留空间时可能输出
