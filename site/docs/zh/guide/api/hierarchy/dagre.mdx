# Dagre 层次布局 <Badge text="Non-Iterative" type="tip" />

用于有向图的分层排列，强调边的方向性与层级关系，常用于 DAG、流程编排与依赖关系等可视化。

<img width="400" src="https://mdn.alipayobjects.com/huamei_qa8qxu/afts/img/A*v5mBSopYr_wAAAAAAAAAAAAADmJ7AQ/original" />

## 适用场景

- 需要明确方向与层级的图，例如 DAG 或流程图
- 需要为边 label/节点尺寸预留空间

## 输入要求

- 节点需要可唯一标识的 `id`
- 需要提供 `edges`，并确保 `source/target` 可对应到节点 id
- 若使用 `compound` 以表达嵌套结构，需要为节点提供 `parentId`。你可以通过 `node` 映射函数适配该字段。

## 用法

```ts
import { DagreLayout } from '@antv/layout';

const layout = new DagreLayout({ width: 800, height: 600, rankdir: 'TB' });
await layout.execute(data);
```

### 算法配置

`DagreLayoutOptions` 在 dagre 的 `GraphLabel` 基础上提供了一组更贴近图可视化的数据适配配置：

| 配置项 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `directed` | 是否按有向图处理 | `boolean` | `true` |
| `compound` | 是否支持嵌套结构 | `boolean` | `true` |
| `multigraph` | 是否允许多重边 | `boolean` | `true` |
| `nodeSize` | 节点尺寸，用于占位与间距计算。 | `Size \| (node)=>Size` | `[0, 0]` |
| `edgeMinLen` | 边跨越的最小层数 | `number \| (node)=>number` | `1` |
| `edgeWeight` | 边权重，用于影响优化优先级。 | `number \| (node)=>number` | `undefined` |
| `edgeLabelSize` | 边标签尺寸，用于预留空间。 | `Size \| (node)=>Size` | `undefined` |
| `edgeLabelPos` | 边标签位置 | `EdgeLabelPos \| (node)=>EdgeLabelPos` | `undefined` |
| `edgeLabelOffset` | 标签与边的偏移 | `number \| (node)=>number` | `undefined` |

:::tip
除以上字段外，其余 dagre `GraphLabel` 选项也可配置，例如 `rankdir`、`nodesep`、`ranksep`。这些字段会直接用于布局计算。
:::

### Dagre GraphLabel

以下字段来自 dagre 的 `GraphLabel`，会被直接用于 dagre 计算。它们与 `@antv/layout` 的通用 `width/height` 不同。这里的 `width/height` 表示 dagre 的图标签宽高，主要用于内部计算与约束。

| 字段 | 说明 | 类型 |
| --- | --- | --- |
| `rankdir` | 布局方向，例如 TB、BT、LR、RL | `string` |
| `align` | 节点对齐方式 | `string` |
| `nodesep` | 同层节点间距 | `number` |
| `edgesep` | 同层边间距 | `number` |
| `ranksep` | 层间距 | `number` |
| `marginx` / `marginy` | 边界留白 | `number` |
| `acyclicer` | 打破环的策略 | `string` |
| `ranker` | 排序策略 | `string` |
| `width` / `height` | dagre 图标签宽高 | `number` |
| `compound` | 是否启用 compound 以支持嵌套 | `boolean` |

## 输出字段

层次布局会在边结果上输出额外信息，例如折线控制点。可通过 `forEachEdge` 读取：

- `edge.points?: Point[]`
- `edge.labelPos?` / `edge.labelOffset?` / `edge.labelSize?`
