# 通用 API <Badge text="Core" type="tip" />

本页描述 `@antv/layout` 的通用调用方式，包括输入数据结构、执行与结果读取、迭代控制与生命周期方法。不同布局算法的差异主要体现在各自的 `LayoutOptions` 配置项。

导出清单、类型继承关系与内置布局列表请阅读：[公共 API](./public-api)。

## 输入：GraphData

```ts
type GraphData<N = Record<string, any>, E = Record<string, any>> = {
  nodes: N[];
  edges?: E[];
};
```

默认约定：

- 节点：`id`
- 边：`source` / `target`

字段不一致时，使用 `node` / `edge` 映射函数适配。相关说明请阅读：[数据转换](../start/data-mapping)。

## 输出：GraphNode / GraphEdge（布局结果结构）

布局计算会生成节点与边的结果对象，并在遍历时返回。该过程不会修改原始 `data`。你最常用到的字段包括：

- `node.id`：节点 id（映射后的）
- `node.x / node.y / node.z?`：布局坐标
- `node._original`：指向原始业务节点对象（用于回写/取额外字段）

边结果常用字段：

- `edge.source / edge.target`：端点 id
- `edge._original`：指向原始业务边对象
- `edge.points / edge.labelPos / ...`：部分层次与流程图布局会输出控制点与标签信息

不同布局可能会输出额外字段。建议以对应布局页为准，例如 [Dagre](./dagre)、[AntVDagre](./antv-dagre)、[ComboCombined](./combo-combined)。

## 核心方法（入参/出参）

### `new XxxLayout(initialOptions?)`

```ts
const layout = new CircularLayout(initialOptions);
```

### `execute(data, userOptions?) => Promise<void>`

```ts
await layout.execute(data, userOptions);
```

| 参数 | 说明 | 类型 |
| --- | --- | --- |
| `data` | 图数据 | `GraphData` |
| `userOptions` | 本次执行的配置，会与构造参数合并 | `Partial<LayoutOptions>` |
| 返回值 | 无（结果通过遍历方法读取） | `Promise<void>` |

`initialOptions` 与 `userOptions` 的合并策略请阅读：[图布局配置](../start/layout-configuration)。

### `forEachNode(callback) => void`

读取节点布局结果：

```ts
layout.forEachNode((node) => console.log(node.id, node.x, node.y));
```

回调入参（常用字段）：

- `id`：节点 id
- `x/y/z`：布局坐标
- `_original`：原始节点数据引用（用于回写/关联）

### `forEachEdge(callback) => void`

读取边的结果：

```ts
layout.forEachEdge((edge) => console.log(edge.source, edge.target));
```

回调入参（常用字段）：

- `id`：边 id（可选）
- `source/target`：端点 id
- `_original`：原始边数据引用
- `points/labelPos/...`：部分布局会输出额外边信息（详见各布局页）

## 数据转换（适配业务字段）

当业务字段不是 `id/source/target` 时，请使用 `node` / `edge` 映射函数进行适配。相关说明请阅读：[数据转换](../start/data-mapping)。

## 迭代布局（可选）

仿真/迭代类布局会额外提供：

| 方法 | 入参 | 出参 |
| --- | --- | --- |
| `tick(iterations?)` | `number` | `void` |
| `stop()` | - | `void` |
| `restart()` | - | `void` |
| `setFixedPosition(nodeId, position)` | `ID`, `Point \| null` | `void` |

你可以使用 `isLayoutWithIterations` 在运行时判断布局实例是否支持迭代能力。导出位置与内置布局列表请阅读：[公共 API](./public-api)。

## 生命周期：destroy（推荐）

布局实例会维护计算上下文。在启用 Worker 时还可能持有 Worker 等资源。不再使用时建议调用：

```ts
layout.destroy();
```
