# Circular 圆形布局 <Badge text="Non-Iterative" type="tip" />

将节点排列在圆周上，也可以配置为螺旋分布。支持节点排序、分组、起止角度与半径控制等能力。算法参考论文：[A framework and algorithms for circular drawings of graphs](https://www.sciencedirect.com/science/article/pii/S1570866705000031)。

## 适用场景

- 需要稳定的环形结构，例如关系展示或分组展示
- 需要明确的节点顺序，支持按数据顺序、拓扑或度数排序

## 输入要求

- 节点需要可唯一标识的 `id`
- 当 `ordering` 依赖拓扑时，需要提供 `edges`，并确保 `source/target` 能够对应到节点 id

## 用法

```ts

const layout = new CircularLayout({ width: 800, height: 600, radius: 150 });
await layout.execute(data);
```

### 算法配置

| 配置项      | 说明                                                                                                                                                | 类型                                                                             | 默认值        |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------- |
| radius      | 圆的半径。如果指定了该值，`startRadius` 和 `endRadius` 将被忽略                                                                                     | `number`                                                                         | `null`        |
| startRadius | 螺旋布局的起始半径                                                                                                                                  | `number`                                                                         | `null`        |
| endRadius   | 螺旋布局的结束半径                                                                                                                                  | `number`                                                                         | `null`        |
| startAngle  | 节点放置的起始角度，单位为弧度                                                                                                                      | `number`                                                                         | `0`           |
| endAngle    | 节点放置的结束角度，单位为弧度                                                                                                                      | `number`                                                                         | `2 * Math.PI` |
| clockwise   | 是否按顺时针方向放置节点                                                                                                                            | `boolean`                                                                        | `true`        |
| divisions   | 圆上节点的分组数量。当 `endRadius - startRadius !== 0` 时生效                                                                                       | `number`                                                                         | `1`           |
| ordering    | 节点的排序方式。`null` 表示按数据顺序排列；`'topology'` 表示按拓扑顺序排列；`'topology-directed'` 表示按有向拓扑顺序排列；`'degree'` 表示按度数排列 | `null \| 'topology' \| 'topology-directed' \| 'degree'`                          | `null`        |
| angleRatio  | 节点之间的角度比例。例如 `angleRatio: 1` 时，节点间角度为 `(endAngle - startAngle) / nodeCount`                                                     | `number`                                                                         | `1`           |
| nodeSize    | 节点的大小。与 `nodeSpacing` 配合使用可自动计算半径                                                                                                 | `number \| [number, number] \| ((node: NodeData) => number \| [number, number])` | `undefined`   |
| nodeSpacing | 节点之间的间距。与 `nodeSize` 配合使用可自动计算半径。如果指定了该值，`startRadius` 和 `endRadius` 将被忽略                                         | `number \| ((node: NodeData) => number)`                                         | `undefined`   |

:::note 关于回调入参
表格中的 `NodeData` 指原始业务节点对象，也就是 `GraphData.nodes` 的元素。
:::
