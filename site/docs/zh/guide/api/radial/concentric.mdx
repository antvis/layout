# Concentric 同心圆布局 <Badge text="Non-Iterative" type="tip" />

根据节点的同心值将节点分层。同心值越高越靠近中心。默认的同心值来自节点度数。

<img
  width="400"
  src="https://mdn.alipayobjects.com/huamei_qa8qxu/afts/img/A*KXunQKOLCSAAAAAAAAAAAAAADmJ7AQ/original"
/>

## 适用场景

- 需要按“重要性”分层展示
- 希望中心区域更稳定，例如核心节点聚集

## 输入要求

- 节点需要可唯一标识的 `id`
- 当 `sortBy: 'degree'` 时需要 `edges`，用于度数计算

## 用法

```ts
import { ConcentricLayout } from '@antv/layout';

const layout = new ConcentricLayout({
  width: 800,
  height: 600,
  sortBy: 'degree',
});
await layout.execute(data);
```

### 算法配置

| 配置项           | 说明                                                        | 类型                         | 默认值            |
| ---------------- | ----------------------------------------------------------- | ---------------------------- | ----------------- |
| `preventOverlap` | 是否防止重叠。启用时需要配合 `nodeSize` 或数据中的 `size`。 | `boolean`                    | `false`           |
| `nodeSize`       | 节点大小，用于碰撞检测。                                    | `Size \| (node) => Size`     | `30`              |
| `nodeSpacing`    | 环与环之间最小间距                                          | `number \| (node) => number` | `10`              |
| `sweep`          | 首尾节点之间的弧度差                                        | `number`                     | `undefined`       |
| `equidistant`    | 环间距是否等距                                              | `boolean`                    | `false`           |
| `startAngle`     | 起始角度，单位为弧度                                        | `number`                     | `3 / 2 * Math.PI` |
| `clockwise`      | 是否顺时针                                                  | `boolean`                    | `true`            |
| `maxLevelDiff`   | 每层同心值差异上限。未设置时自动推断。                      | `number`                     | `undefined`       |
| `sortBy`         | 同心值依据。默认按度数计算。                                | `'degree' \| (node)=>number` | `'degree'`        |

:::tip
如果“重要性”不是度数，可以通过 `sortBy: (node) => number` 自定义同心值。
:::
