# 简介

`@antv/layout` 是面向图可视化的布局算法库。内置多种常用布局算法，统一图数据与布局接口，将图结构计算为可渲染的坐标布局。<Badge type="tip">TypeScript</Badge><Badge type="info" outline>WebWorker</Badge>

## 布局一览

| 类型           | 布局                                                                                            | 布局                                                                       |
| -------------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 力导向（迭代） | [ForceAtlas2](./api/force/force-atlas2)<br />大规模图，支持加速。                              | [Force](./api/force/force)<br />参数丰富，便于调参与过程控制。            |
|                | [Fruchterman](./api/force/fruchterman)<br />经典力导向，适合中小规模图。                       | [D3Force](./api/force/d3-force)<br />基于 d3-force 的仿真封装。           |
|                | [D3Force3D](./api/force/d3-force-3d)<br />3D 力导向，输出 z 坐标。                             |                                                                            |
| 层次/流程图    | [Dagre](./api/hierarchy/dagre)<br />有向层次布局，支持标签与占位。                             | [AntVDagre](./api/hierarchy/antv-dagre)<br />面向工程的层次布局增强实现。 |
| 环形/辐射      | [Circular](./api/radial/circular)<br />圆周/螺旋分布，支持排序与角度控制。                     | [Concentric](./api/radial/concentric)<br />按同心值分层，突出中心节点。   |
|                | [Radial](./api/radial/radial)<br />以焦点节点为中心的辐射结构。                                |                                                                            |
| 规则/初始化    | [Grid](./api/regular/grid)<br />规则网格排布，位置稳定可预测。                                 | [Random](./api/regular/random)<br />生成随机坐标，用于占位或热启动。      |
| 其他           | [MDS](./api/others/mds)<br />距离约束驱动的降维布局。                                          |                                                                            |
| 复合/Combo     | [ComboCombined](./api/combo/combo-combined)<br />多层级复合布局，统一处理 Combo 包围盒与间距。 |                                                                            |

:::tip 最小示例

下面以 `CircularLayout` 为例，展示一次最小的布局调用流程：

```ts
import { CircularLayout } from '@antv/layout';

const data = {
  nodes: [{ id: 'node1' }, { id: 'node2' }, { id: 'node3' }],
  edges: [
    { source: 'node1', target: 'node2' },
    { source: 'node2', target: 'node3' },
  ],
};

async function run() {
  const layout = new CircularLayout({ center: [200, 200], radius: 150 });

  await layout.execute(data);

  layout.forEachNode((node) => {
    console.log(node.id, node.x, node.y);
  });
}

run();
```

:::
