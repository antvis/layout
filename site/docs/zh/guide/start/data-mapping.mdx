# 数据转换

本章节介绍如何将业务数据结构适配到布局算法的输入要求。

:::note
如果你已经使用标准图数据结构，也就是节点字段为 `id`，边字段为 `source` / `target`，可以跳过本章节。
:::

## 为什么需要数据映射？

布局算法依赖一些关键字段，例如节点 id、边的 `source/target`、可选的初始坐标。实际业务数据的字段命名往往不同。通过数据映射，你可以在不改动原始数据的前提下完成字段适配。

### 业务数据示例

假设你的业务数据结构如下：

```js
const data = {
  nodes: [
    { nodeId: 'n1', position: { x: 100, y: 200 }, radius: 16 },
    { nodeId: 'n2', position: { x: 300, y: 200 }, radius: 16 },
  ],
  edges: [{ edgeId: 'e1', from: 'n1', to: 'n2', weight: 2 }],
};
```

:::warning
直接使用上述数据执行布局会失败，因为字段名为 `nodeId`、`from`、`to`，与默认约定的 `id`、`source`、`target` 不一致。
:::

## 配置数据映射

在布局初始化或执行时传入 `node` / `edge` 映射函数即可完成字段转换。

:::tip 只映射“关键字段”
映射函数只需要返回布局计算必需的字段，例如 `id`、`source`、`target`、`x`、`y`。其他业务字段不需要额外拷贝。布局结果对象会保留 `_original` 指向原始业务对象，便于读取与回写。
:::

### 节点映射配置

```js
const layout = new CircularLayout({
  center: [500, 500],
  node: (datum) => ({
    id: datum.nodeId,
    x: datum.position?.x,
    y: datum.position?.y,
  }),
});
```

映射函数接收单个原始节点数据，返回布局计算所需的字段：

**映射字段说明：**

| 字段      | 是否必需 | 说明 |
| --------- | -------- | ---------------------------- |
| `id`      | ✅       | 节点唯一标识符 |
| `x` / `y` |          | 初始位置。可选，用于热启动。 |
| `z` |          | 3D 初始位置。可选，用于 3D 布局热启动。 |
| `parentId` / `isCombo` |          | 复合或 Combo 布局所需的层级信息，例如 Dagre、AntV-Dagre、ComboCombined。 |

### 边映射配置

```js
const layout = new CircularLayout({
  edge: (datum) => ({
    id: datum.edgeId,
    source: datum.from,
    target: datum.to,
  }),
});
```

**映射字段说明：**

| 字段     | 是否必需 | 说明 |
| -------- | -------- | --------------------------------------- |
| `id`     |          | 边唯一标识符 |
| `source` | ✅       | 起点节点 ID，必须与某个节点的 `id` 匹配 |
| `target` | ✅       | 终点节点 ID，必须与某个节点的 `id` 匹配 |

:::note 边的 id 不传也可以
若不提供 `id`，会基于 `source-target` 自动生成。在存在多条平行边时会追加序号，例如 `a-b-1`。
:::

## 常见扩展：让算法读取业务字段

不少布局的配置项支持回调函数，例如 `nodeSize(node)`、`linkDistance(edge)`。这类回调通常会拿到原始业务对象，因此你可以在业务数据里提供字段，再在回调里读取：

```ts
import { ForceLayout } from '@antv/layout';

const layout = new ForceLayout({
  nodeSize: (node) => node.radius ?? 16,
  linkDistance: (edge) => edge.weight ? 80 / edge.weight : 200,
});
```

## 完整示例

以下示例展示完整的数据映射流程：

```js
const data = {
  nodes: [
    { nodeId: 'n1', position: { x: 100, y: 200 }, radius: 16 },
    { nodeId: 'n2', position: { x: 300, y: 200 }, radius: 16 },
  ],
  edges: [{ edgeId: 'e1', from: 'n1', to: 'n2', weight: 2 }],
};

const layout = new CircularLayout({
  center: [500, 500],
  node: (datum) => ({
    id: datum.nodeId,
    x: datum.position?.x,
    y: datum.position?.y,
  }),
  edge: (datum) => ({
    id: datum.edgeId,
    source: datum.from,
    target: datum.to,
  }),
});

await layout.execute(data);

layout.forEachNode((node) => {
  console.log(node.id, node.x, node.y);
});
```

布局过程中不会修改原始数据；映射逻辑仅用于计算过程，并会生成布局结果对象用于遍历读取。
