# 简介

`@antv/layout` 是面向图可视化的布局算法库。它提供统一的数据模型与调用方式，用于将节点与边计算为可渲染的坐标结果。<Badge type="tip">TypeScript</Badge><Badge type="info" outline>WebWorker</Badge>
