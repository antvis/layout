#Grid 网格布局Non-Iterative

将节点按行列排列到规则网格上，适用于需要稳定、可预测结构的场景，例如矩阵视图或卡片式列表布局。

#适用场景

  • 规则排布、可预测位置
  • 需要通过 rows/cols 控制布局密度

#输入要求

  • 节点需要可唯一标识的 id

#用法

import { GridLayout } from '@antv/layout';

const layout = new GridLayout({ width: 800, height: 600, rows: 8, cols: 10 });
await layout.execute(data);

#配置项

#通用配置

以下配置项适用于所有布局，用于定义布局参考尺寸、中心点、Worker 与数据字段映射。

配置项说明类型默认值
width / height布局参考尺寸。多数布局会基于该值推导默认中心或缩放范围。numberundefined
center布局中心点。2D 使用 [x, y]，3D 使用 [x, y, z]。[number, number] | [number, number, number]undefined（由各布局决定）
enableWorker是否在 Web Worker 中执行。Worker 不可用时会自动回退到主线程。booleanfalse/undefined（由各布局决定）
node节点字段映射，用于适配业务字段。(datum) => ({ id?, x?, y?, z?, parentId?, isCombo? })undefined
edge边字段映射，用于适配业务字段。(datum) => ({ id?, source?, target? })undefined

#node 映射字段

  • id：节点唯一标识，必需。
  • x/y/z：初始坐标，可选。用于热启动或连续布局。
  • parentId：父级 Combo id。用于复合或嵌套布局。
  • isCombo：是否为 Combo 节点。用于复合布局。

#edge 映射字段

  • source / target：端点节点 id，必需。需要能够对应到某个节点的 id。
  • id：边唯一标识，可选。未提供时会自动生成。
