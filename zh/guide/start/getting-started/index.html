在开始之前，请先完成安装与引入：安装。

#基础用法

本节用最小流程说明如何执行一次布局计算，并读取结果。

#1. 准备图数据

@antv/layout 使用统一的图数据结构：

const data = {
  nodes: [{ id: 'node1' }, { id: 'node2' }, { id: 'node3' }],
  edges: [
    { source: 'node1', target: 'node2' },
    { source: 'node2', target: 'node3' },
  ],
};

数据结构包含 nodes 数组与可选的 edges 数组。默认约定：节点使用 id，边使用 source / target。

#2. 布局初始化

从 @antv/layout 按需引入布局算法：

import { CircularLayout } from '@antv/layout';

然后创建算法实例，并传入初始化参数：

const layout = new CircularLayout({
  center: [200, 200],
  radius: 150,
});

构造参数也可以在执行时覆盖。

#3. 执行布局

调用 execute 开始计算布局（不会修改原始数据）：

await layout.execute(data);

也可以在执行算法时传入参数：

await layout.execute(data, {
  center: [200, 200],
  radius: 150,
});

#4. 读取布局结果

布局完成后，可以通过 forEachNode 遍历节点位置结果：

layout.forEachNode((node) => {
  console.log(`节点 ${node.id}: (${node.x}, ${node.y})`);
});

也可以使用 forEachEdge 遍历边的结果。

layout.forEachEdge((edge) => {
  console.log(`边 ${edge.source} → ${edge.target}`);
});

#清理资源

布局实例会维护计算上下文，并且在启用 Worker 时可能持有 Worker 等资源；不再使用时建议调用 destroy()：

layout.destroy();
